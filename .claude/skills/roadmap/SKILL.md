# roadmap

Read `docs/ROADMAP.md`. Report the current phase, what is checked off, and the single next
unchecked item.

A step is finished when a passing test, or a run in a real chat workspace, shows it working.
A scaffold that raises `NotImplementedError` is not finished. Say which test or run supports each
claim.

Do not mark an item complete in the doc without one to point at.
